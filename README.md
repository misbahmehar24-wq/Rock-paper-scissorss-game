# Rock Paper Scissors Game

## Aim
To develop a Rock Paper Scissors game using the C programming language.

## Description
This is a console-based game in which the user plays against the computer.

## Rules
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both choices are the same, the game is a draw.

## Language Used
C Programming Language

## Features
- Random computer choice
- Winner determination
- Simple and interactive gameplay
- Option to play again
